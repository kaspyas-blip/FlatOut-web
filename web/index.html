    Changes from the original

    The PC game's own code (FlatOut.exe, 2004), translated to C ahead of time and compiled to WebAssembly. Direct3D 9 runs on WebGPU, DirectSound on Web Audio, and LAN play on this server's virtual LAN: everyone who opens this page on the same server can race together in the game's LAN mode.

    You bring your own copy of the game: the server reads the install folder, and nothing of the game is in this project. The intro movies are not played yet.

    About this project

    A fan port of FlatOut (Bugbear Entertainment, 2004) to the browser, for players who own the game.

    Credits

    The browser runtime (Windows, Direct3D 9 on WebGPU, Web Audio, the virtual LAN) and the x86 to C lifter come from th0mk's nfsu2-web (MIT), based on Talha Müderrisoğlu's NFSU2Recomp, which follows the method of N64: Recompiled and XenonRecomp. Function recovery uses pcrecomp and Capstone.
